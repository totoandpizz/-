# 히즈빈스 말씀 카드

롱블랙 Play '문장 운세'(longblack.co/play/fortune)의 화면 흐름을 따르고, 내용은 성경 구절, 색은 히즈빈스 흰색과 녹색으로 바꾼 정적 페이지입니다.

- `index.html`: 화면과 동작
- `verses.js`: **고정 구절 데이터.** 단어, 기분, 단어별 구절 2개(본문, 장절, 해설, 오늘의 한 잔, 작은 실천)

## 흐름

0. 인트로: 큰 날짜 위에 떠 있는 카드, '당신을 위한 / 말씀으로 읽는 오늘의 한 잔'
1. 오늘의 단어를 고르세요: 강점, 함께, 쉼, 시작, 다름, 용기, 대화, 자리
2. 지금 기분은 어떠신가요?: 위아래로 굴리는 휠
3. 마음이 가는 패턴을 고르세요: 녹색 패턴 8종
4. 카드 섞기, 그리고 눌러서 뒤집기
5. 결과: 패턴과 말씀, 장절이 담긴 카드, 기분별 한마디, 해설, 오늘의 한 잔, 작은 실천, 다시 하기, 말씀 복사

같은 날짜 + 단어 + 기분 + 패턴이면 늘 같은 구절이 나옵니다.

## 구절 수정

`verses.js`의 `VERSES`에서 단어별 배열을 고치면 됩니다. 본문은 개역한글판 기준으로 옮겨 적었으니, 공개 전 성경 본문과 한 번 더 대조해 주세요. 개역개정판으로 바꾸려면 대한성서공회 사용 허가가 필요할 수 있습니다.

## 색

히즈빈스 사이트(hisbeans.com)에서 뽑은 브랜드 그린 `#1D462A`를 기본으로, 리프 그린 `#3E8E5A`, 민트 `#DCEBDF`, 흰색 배경을 씁니다. 화면 구조와 크기는 롱블랙 화면에서 측정한 값입니다(Pretendard, 모서리 8px).

## 이미지

인트로 카드와 패턴 8종은 Higgsfield(`gpt_image_2_5`)로 생성했고 Higgsfield CDN 주소로 불러옵니다. 불러오지 못하면 각 패턴의 대표색이 보입니다.
