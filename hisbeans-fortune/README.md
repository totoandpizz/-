# 히즈빈스 오늘의 한 문장

롱블랙 Play의 '오늘의 문장 운세' 형식(고르기 → 한 문장 → 해설)을 히즈빈스 톤앤매너로 다시 짠 인터랙티브 페이지입니다. `index.html`을 브라우저로 열면 됩니다.

## 흐름

1. 이름(선택)을 적고 원두 6종 중 하나를 고릅니다.
2. '오늘의 문장 내리기'를 누르면 추출 노트가 나옵니다.
3. 노트 구성: 키워드 태그 · 오늘의 문장 · 해설 · 추출 레시피(원두 g / 비율 / 시간) · 오늘의 한 잔 · 오늘의 작은 실천
4. 같은 날짜 + 이름 + 원두면 늘 같은 결과가 나옵니다. 문장은 복사해서 공유할 수 있습니다.

## 톤앤매너 원칙

- **바리스타가 건네는 한마디.** 점쟁이의 예언이 아니라, 바 너머에서 듣는 다정한 말투(~해요).
- **강점에 먼저 눈 맞추기.** 부족함을 지적하지 않고 잘하는 것, 맞는 자리를 이야기합니다.
- **함께.** 한 잔에 여러 사람의 손이 담긴다는 브랜드 정체성을 문장 곳곳에 녹입니다.
- **커피의 언어로.** 추출, 온도, 숙성, 첫 샷처럼 커피 만드는 과정을 비유로 씁니다.
- **실천은 작게.** 오늘 바로 할 수 있는 5~15분짜리 행동 하나.

## 콘텐츠 추가

`index.html`의 `LINES` 배열에 `{ tag, s(문장), r(해설), d(오늘의 한 잔), a(작은 실천) }`를 추가하면 됩니다. 현재 12개 문장은 모두 새로 쓴 것이며 롱블랙 원문을 옮기지 않았습니다.

## 이미지

히어로 사진과 원두 6종 일러스트는 Higgsfield(`gpt_image_2_5`)로 생성했고, Higgsfield CDN 주소를 그대로 씁니다. 이미지를 불러오지 못하면 히어로는 숨겨지고 원두 카드는 SVG 아이콘으로 바뀝니다.
