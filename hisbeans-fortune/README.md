# 히즈빈스 문장 운세

롱블랙 Play의 '문장 운세'(longblack.co/play/fortune) 화면 구조를 그대로 따르고, 내용은 히즈빈스 톤으로 바꾼 페이지입니다. `index.html`을 브라우저로 열면 됩니다.

## 흐름 (롱블랙과 동일)

0. **인트로**: 큰 날짜(year · month · day) 위에 떠 있는 카드, '당신을 위한 / 한 잔으로 읽는 오늘의 운세', `오늘의 카드 만들기`
1. **오늘의 단어를 고르세요**: 2열 8칸 타일. 선택하면 오렌지, 그 전엔 `다음` 버튼 비활성
2. **지금 기분은 어떠신가요?**: 위아래로 굴리는 휠. 가운데 단어가 오렌지로 커짐
3. **마음이 가는 패턴을 고르세요**: 2열 8칸 패턴 이미지
4. **셔플 → 뒤집기**: '원두를 다 갈았어요. 이제 내릴 차례예요.' 별 그라디언트 카드 뒷면 → 탭하면 카드가 뒤집히고, 고른 패턴이 배경에 깔림
5. **결과**: 카드 앞면(패턴 + 오늘의 문장) 아래에 기분별 한마디, 해설, 오늘의 한 잔, 오늘의 작은 실천, `다시 하기` · `문장 복사`

같은 날짜 + 단어 + 기분 + 패턴이면 늘 같은 문장이 나옵니다.

## 디자인 토큰 (롱블랙 화면에서 측정)

- 배경 `#111111`, 헤더 · 푸터 `#252525`, 타일 `#262626`, 포인트 `#FF5A2B`, 날짜 숫자 `#666666`
- 서체 Pretendard. 날짜 80px/400, 제목 26px/700, 버튼 16px/600, 모서리 8px
- 롱블랙 로고와 이름은 쓰지 않고 `HisBeans` 워드마크로 바꿨습니다.

## 톤앤매너

- 바리스타가 바 너머에서 건네는 다정한 말투(~해요)
- 부족함보다 잘하는 것과 맞는 자리에 먼저 눈 맞추기
- 한 잔에 여러 사람의 손이 담긴다는 '함께'
- 추출, 온도, 숙성, 첫 샷 같은 커피의 언어로 비유
- 실천은 오늘 바로 할 수 있는 5~15분짜리 하나

## 콘텐츠 수정

`index.html`의 `WORDS`(단어 8개), `MOODS`/`MOOD_NOTE`(기분 8개와 한마디), `LINES`(단어별 문장 2개: `s` 문장, `r` 해설, `d` 오늘의 한 잔, `a` 작은 실천)를 고치면 됩니다. 문장 16개는 모두 새로 쓴 것이며 롱블랙 원문을 옮기지 않았습니다.

## 이미지

인트로 카드와 패턴 8종은 Higgsfield(`gpt_image_2_5`)로 생성한 플랫 그래픽이며 Higgsfield CDN 주소로 불러옵니다. 이미지를 불러오지 못하면 각 패턴의 대표색이 대신 보입니다.
